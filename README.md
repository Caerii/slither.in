# slither.in (repo)

This repo contains **slither.in**, a dating site for worms.

- **Live site**: `https://slitherin.vercel.app/`
- **Source**: `https://github.com/Caerii/slither.in`

![slither.in screenshot](./slither.in/public/live-screenshot.png)

## Where the app lives

The actual Vite app is in the `slither.in/` directory.

```bash
cd slither.in
npm install
npm run dev
```

## Deploy (Vercel)

Set Vercel **Root Directory** to `slither.in`, then build normally (`npm run build`) with output `dist`.
