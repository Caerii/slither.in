# slither.in

A dating site for worms.  
Yes, it’s serious. No, the worms aren’t.

- **Live**: `https://slitherin.vercel.app/`

![slither.in screenshot](./public/live-screenshot.png)

- **Discover**: swipe on extremely eligible annelids
- **Chat**: press dialogue buttons or **Wriggle!** (no typing, only vibes)
- **Squiggle**: dodge boots + robins, eat snacks, chase combos, become legend

## Play locally (Vite)

```bash
pnpm install
pnpm run dev
```

Then open `http://localhost:3000`.

## Deploy on Vercel

This repo is a monorepo-ish situation: the app lives in the `slither.in/` folder.

- **Root Directory**: `slither.in`
- **Framework**: Vite
- **Build Command**: `pnpm run build`
- **Output Directory**: `dist`
